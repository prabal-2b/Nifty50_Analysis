# NIFTY 50 Index Data Analysis (2015–2025)

## Project Description

This project focuses on analyzing historical NIFTY 50 Index data from 2015 to 2025, sourced from the official National Stock Exchange (NSE) of India website.

The dataset was imported into MySQL Workbench, cleaned and prepared for analysis, and queried using SQL to identify market trends, price movements, and other meaningful patterns. Power BI was used to create visualizations that make the findings easier to understand.

The primary objective is to explore historical index performance and present data-driven insights that can help users better understand market behavior.


## Project Objectives

- Analyze historical NIFTY 50 Index data from 2015 to 2025.
- Prepare and transform data for accurate analysis.
- Use SQL queries to examine market trends and price movements.
- Identify meaningful patterns in historical index performance.
- Create interactive visualizations using Power BI.
- Present important findings to support a better understanding of the stock market.

## 🔄 Work Sequence

1. **Data Collection:** Obtained historical NIFTY 50 Index data from the official NSE website.
2. **Data Import:** Imported the dataset into MySQL Workbench.
3. **Data Preparation:** Examined data types, date formats, missing values, and data consistency.
4. **SQL Analysis:** Wrote SQL queries to analyze index performance and identify trends.
5. **Insight Extraction:** Documented important findings from the analysis.
6. **Data Visualization:** Created charts and visuals using Power BI.
7. **Documentation:** Organized the SQL scripts, analysis findings, and project documentation.

## Technologies Used
